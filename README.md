Full-stack MERN portfolio + CMS. Deploy to Railway/Vercel in 5 minutes!

## 🎯 Quick Deploy

### Railway + Vercel (Recommended ✅)
```bash
# Backend (Railway)
1. railway login
2. railway new  (select backend/)
3. Add vars from .env.example
4. Deploy!

# Frontend (Vercel)
1. vercel login
2. vercel --prod (in frontend/)
```

### Docker Local
```bash
docker compose up -d
```

## 📋 Setup (2 minutes)

1. **Copy env**: `cp .env.example .env`
